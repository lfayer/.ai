# Brief Templates

## Short-form prompt template

Write a [blog post / essay / memo] for [technical ICs / technical leaders].

Topic: [topic]
Working thesis: [what the piece should argue]
Length: [rough length or depth]
Mode: [faithful / refined]
Must include:
- [point 1]
- [point 2]
- [point 3]
Source material:
- pasted text: [yes/no]
- URLs: [list]
Constraints:
- [SEO, publication, timing, calls to action, examples to include or avoid]

- pasted notes: [yes/no]

- [theme 1]
- [theme 2]
- [theme 3]

- [theme or framing to avoid]
